Expense & Budget Tracker
-> A sleek, responsive, and interactive personal finance web application built using vanilla JavaScript, HTML5, CSS3, and Chart.js.

Features
- Real-Time Balance Tracking: Automatically calculates total balance, income, and expenses.
- Categorized Transactions: Tag income and expenses under specific categories (Food, Shopping, Bills, Rent, Salary, Other).
- Dynamic Expense Visualization: Interactive Doughnut Chart powered by Chart.js that updates live as expenses are added or removed.
- Data Persistence: Uses browser localStorage so transaction history stays saved even after page reloads.
- Modern Fintech UI: Clean, high-contrast card layout with responsive design.

Tech Stack
- Frontend: HTML5, CSS3 (Custom Properties, Flexbox, Gradients)
- Logic & State: Vanilla JavaScript (ES6+)
- Data Visualization: Chart.js
- Storage: Web Storage API (localStorage)
